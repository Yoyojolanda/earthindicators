How the numbers are made

Every chart on this site is drawn from public data published by the agencies that measure it. This page lists, for each indicator, the exact dataset and version, the files that are downloaded, what this site does with them, how often they update, and how the results are checked.

All of the code is public in the earthindicators repository on GitHub. The data files the pages draw from live in its data folder, and every automatic update is a commit, so the full history of every number can be inspected.

Two kinds of series
Published series, shown as published. For CO₂, methane, ocean heat content, sea level, sea ice and the energy imbalance, the site downloads the agency's own file and plots its values unchanged. Anything derived from them (running means, trends, growth rates, comparisons) is calculated in your browser by the page's own script, which you can read on GitHub.
Series calculated here from gridded data. For El Niño, sea surface temperature and part of the air temperature record, the agencies publish maps rather than a single number per day, so this site averages the maps itself. Those calculations are checked against independently published series wherever one exists, and the results of those checks are shown below.

Air temperature

Used on: Air temperature, the overview and the claims page.

Dataset

Copernicus Climate Change Service (C3S), ERA5 post-processed daily statistics on single levels, variable 2 m temperature, daily mean of all 24 hourly values (UTC). DOI 10.24381/cds.4991cf48. ERA5 reference: Hersbach et al. (2020), doi:10.1002/qj.3803.

World history (1940 to 18 February 2024): the daily global series published by Copernicus, era5_daily_series_2t_global_1940-2024.csv, using only days it marks FINAL.

What this site does

From 19 February 2024 onward, the daily-mean temperature field (0.25° grid) is downloaded from the Copernicus Climate Data Store and averaged over the globe with each grid cell weighted by the cosine of its latitude (its share of Earth's area), then converted from kelvin to °C. This is the same method Copernicus uses for its published series.

Regions are calculated the same way over their own latitude bands: Northern and Southern Hemisphere (0–90°), Arctic and Antarctic (beyond 66.5°) and tropics (23.5°S–23.5°N). Their history is being filled in back to 1940, several months at a time; a region appears on the page once 1991–2020 is complete.

Every day of the year gets a 1991–2020 average (smoothed with a 5-day centred running mean); the anomaly is the day's value minus that average. "Above pre-industrial" adds Copernicus's offset of 0.88 °C (1850–1900 to 1991–2020), applied to 12-month averages only.

Warming by region
The bar chart of warming rates is the least-squares linear trend of each region's yearly average, from 1979 to the last complete year, using only years with every day present. The world bar uses the series described above; the regions use this site's own calculation.
Updates
Daily. ERA5 runs about 5 days behind real time. The newest 10 days are recalculated on every run, because the early-release data (ERA5T) can still be revised.
Checks

Code
scripts/build_era5.py (world), scripts/build_era5_regions.py (regions), run by update-era5.yml and update-era5-regions.yml.
Data as used
era5_t2_global_daily.csv (one row per day; the source column says whether a value is Copernicus's published one or calculated here), era5_t2_global_day.json, era5_t2_regions_daily.csv.
Limitations
ERA5 is a reanalysis: a weather model constrained by billions of observations, not a direct measurement. Day-to-day values are reliable for the globe; for small or data-sparse regions such as the Antarctic, single days are less certain than long averages.

El Niño (Niño 3.4)

Used on: El Niño.

Dataset
NOAA 0.25° Daily Optimum Interpolation Sea Surface Temperature (OISST), version 2.1, DOI 10.25921/RE9P-PT57; Huang et al. (2021), doi:10.1175/JCLI-D-20-0166.1. Read as yearly files (sst.day.mean.YYYY.nc) from the NOAA PSL server, which downloads only the box needed.
What this site does

Takes every grid point in the Niño 3.4 box (5°S–5°N, 170°W–120°W) for every day since 1982 and averages them, weighted by the cosine of latitude.

The anomaly is the daily value minus the 1991–2020 average for that day of the year (smoothed with a 5-day running mean). This is not NOAA's official Oceanic Niño Index, which uses 3-month means, and not the newer relative index that subtracts the tropical mean.

Updates
Daily. The current and previous year are downloaded again on every run, because NOAA first publishes preliminary values and replaces them with final ones about two weeks later.
Checks

Compared with the Niño 3.4 series from Climate Reanalyzer (University of Maine), which is calculated independently from the same NOAA data. A saved copy of their series is kept in the repository as reference/climatereanalyzer.json.

Loading…

Both sites publish values rounded to 0.001 °C, so differences of 0.001 °C are rounding. The few larger differences fall in short clusters: most in the last weeks of a year, when NOAA swaps preliminary values for final ones, so the two sites probably downloaded at different moments. A cluster in early January 2012 has not been explained yet.

Code
scripts/build_nino34.py, run by update-nino34.yml.
Data as used
nino34_daily_sst.csv (one row per day), oisst2.1_nino3.4_sst_day.json (by year, with the 1991–2020 average).

Sea surface temperature

Used on: Sea surface temperature, the overview and the claims page.

Dataset
NOAA OISST v2.1, as for El Niño above.
What this site does

The same script and method as Niño 3.4, applied to larger areas. Land has no SST values, so only ocean points count.

  • World: 60°S–60°N, every fourth grid point (a 1° sample)
  • North Pacific: 0–60°N, 120°E–100°W, every third grid point
  • North Atlantic: 0–60°N, 0–80°W, every second grid point
  • Subpolar North Atlantic: 45–60°N, 20–45°W
  • Atlantic hurricane region: 10–20°N, 20–85°W
  • Gulf of Maine: 42–45°N, 66–71°W
  • Gulf of Mexico: 20–30°N, 82–98°W

Except for the North Pacific, the boxes follow Climate Reanalyzer's definitions. Baseline and anomalies as for El Niño.

Updates
Daily, with the current and previous year downloaded again on every run.
Checks
The averaging code is the one checked for Niño 3.4 above. The world and regional series have not yet been compared with an independently published series; when such a comparison is added, its result will appear here.
Code
scripts/build_nino34.py, run by update-global.yml (world) and update-sst-regions.yml (regions, each with its exact box).
Data as used
world_daily_sst.csv and oisst2.1_world_sst_day.json; each region has the same pair of files in the data folder.
Limitations
Sampling every second, third or fourth grid point speeds up the download for large areas; it changes the average very little but is not identical to using every point.

Ocean heat content

Used on: Ocean heat and the energy imbalance comparison.

Dataset
NOAA National Centers for Environmental Information (NCEI), Global Ocean Heat and Salt Content, basin time series for the world ocean (w0), Atlantic including the Arctic (a0), Pacific (p0) and Indian Ocean (i0), 0–2000 m (from 2005) and 0–700 m (from 1955), yearly and 3-monthly. Method: Levitus et al. (2012), doi:10.1029/2012GL051106. Files are taken from this NCEI folder.
What this site does
Plots NOAA's values unchanged, converted from NOAA's unit (10²² joules) to zettajoules (10²¹ J), with NOAA's ±2 standard error band. Anomalies are relative to NOAA's 1955–2006 climatology. Heating rates are least-squares linear trends, converted to watts per square metre of Earth's whole surface (510 million km²).
Updates
Checked weekly; NOAA updates every three months.
Code
Download: update-ohc.yml. Calculations: the script inside ohc.html.
Data as used
The h22-*.dat files in the data folder, byte for byte as NOAA publishes them.
Limitations
Measurements were sparse before the Argo floats reached global coverage in the mid-2000s, so earlier values are less certain. NOAA's estimate is at the low end of published ocean heat estimates.

Sea level

Used on: Sea level.

Dataset
NASA-SSH Global Mean Sea Level from Simple Gridded Sea Surface Height, version 1 (NASA JPL, PO.DAAC), DOI 10.5067/NSIND-GMSV1. Backup: NOAA Laboratory for Satellite Altimetry global mean sea level (star.nesdis.noaa.gov), no longer updated since early 2025.
What this site does
Plots the published values. For the NASA series, the average seasonal cycle (about ±0.6 cm) is removed so the trend stands out: residuals from a quadratic fit are averaged in 26 two-week bins of the year and subtracted. Rates are linear trends; the curve is a quadratic fit. No glacial isostatic adjustment is applied.
Updates
Checked weekly.
Code
Download: update-sealevel.yml. Calculations: the script inside sea-level.html.
Data as used
NASA_SSH_GMSL_INDICATOR.txt, slr_sla_gbl_free_all_66.csv, unchanged.

Sea ice extent

Used on: Sea ice extent.

Dataset
NSIDC / NOAA Sea Ice Index, version 4 (G02135), daily extent for the Arctic and Antarctic. Fetterer, F., K. Knowles, W. Meier et al., DOI 10.7265/a98x-0f50.
What this site does
Extent is NSIDC's: the area where ice concentration is at least 15%. Each value shown is a 5-day trailing mean, which also fills the every-other-day gaps of the 1978–1987 record. Reference period 1981–2010, as used by NSIDC. The standard-deviation chart compares each day with the mean and spread of the same day over a 30-year reference period (1981–2010 or 1991–2020, selectable).
Updates
Daily; the newest days may still be revised by NSIDC.
Code
Download: update-seaice.yml. Calculations: the script inside sea-ice.html.
Data as used
N_seaice_extent_daily_v4.0.csv, S_seaice_extent_daily_v4.0.csv, unchanged.

CO₂

Used on: CO₂.

Dataset
NOAA Global Monitoring Laboratory, Mauna Loa daily mean CO₂, co2_daily_mlo.txt (gml.noaa.gov/ccgg/trends). Dr. Xin Lan, NOAA/GML, and Dr. Ralph Keeling, Scripps Institution of Oceanography.
What this site does
Plots NOAA's daily means unchanged; days without enough valid hourly data are gaps, never filled in. Monthly means use months with at least 10 valid days; the trend is a centred 12-month running mean. Annual growth compares each month with the same month a year earlier.
Updates
Daily.
Code
Download: update-co2.yml. Calculations: the script inside co2.html.
Data as used
co2_daily_mlo.txt, unchanged.

Methane

Used on: Methane.

Dataset
NOAA Global Monitoring Laboratory, globally averaged methane at marine surface sites: monthly means ch4_mm_gl.txt and annual increases ch4_gr_gl.txt. Lan, X., K.W. Thoning and E.J. Dlugokencky (gml.noaa.gov/ccgg/trends_ch4).
What this site does
Plots NOAA's monthly means, de-seasonalised trend and annual increases unchanged. Pre-industrial reference (1750): about 729 ppb (IPCC AR6).
Updates
Checked daily; NOAA updates monthly. First estimates for recent months can be revised by several ppb.
Code
Download: update-ch4.yml. Display: ch4.html.
Data as used
ch4_mm_gl.txt, ch4_gr_gl.txt, unchanged.

Earth's energy imbalance

Used on: Energy imbalance.

Dataset
NASA CERES Energy Balanced and Filled (EBAF) top-of-atmosphere monthly means, Edition 4.2.1, DOI 10.5067/TERRA-AQUA-NOAA20/CERES/EBAF-TOA_L3B004.2.1; Loeb et al. (2018), doi:10.1175/JCLI-D-17-0208.1. NASA Langley Research Center, distributed by the NASA Atmospheric Science Data Center. The newest file is found through NASA's public catalogue (CMR) and downloaded with an Earthdata account; the exact file used is recorded in ceres_source.txt.
What this site does

Takes NASA's own global monthly means from the file (all-sky): incoming solar, reflected shortwave and outgoing longwave radiation. Absorbed solar = incoming minus reflected; energy imbalance = absorbed solar minus outgoing longwave. Only if a file lacked NASA's global means would the script average the 1° grid itself, weighted by the cosine of latitude.

Running means (12 and 48 months) end at the month shown.

Updates
Checked daily; NASA publishes a new file about once a month, a few months behind real time.
Checks
The values are NASA's own global means, not recalculated. As an independent cross-check, the page compares the total heat gain measured by the satellites with the heat gain of the upper 2000 m of the ocean from NOAA over the same 10 years.
Code
scripts/build_ceres.py, run by update-ceres.yml. Calculations: the script inside eei.html.
Data as used
ceres_ebaf_global.csv (month, incoming, absorbed, outgoing, net, in W/m²).
Limitations
The satellites measure the imbalance as a small difference between two very large flows of energy. EBAF therefore anchors the absolute level to ocean heat measurements; the changes over time come from the satellites themselves.

Reproducing and citing

Run it yourself

The scripts need Python 3 with numpy, xarray, netCDF4 and pydap. For example, to rebuild the Niño 3.4 series from NOAA's data:

git clone https://github.com/yoyojolanda/earthindicators
cd earthindicators && python scripts/build_nino34.py --full

The ERA5 scripts also need a free Copernicus Climate Data Store account and the cdsapi package; CERES and the NASA sea level file need a free NASA Earthdata account.

Live numbers
The numbers in the "In short" boxes, on the overview and on the claims page all come from one file, indicators.js, so every page shows the same value.
