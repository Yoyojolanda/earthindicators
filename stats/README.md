# Visitor statistics

Daily exports from [GoatCounter](https://www.goatcounter.com/), the cookie-free counter this site uses.
The live dashboard is public: https://yoyojolanda.goatcounter.com

Each file `goatcounter-YYYY-MM.csv` holds the page views of one month, updated daily: page, title, whether it was an event
(for example `claim-copy/trace-gas`), browser, operating system, referrer, screen size, country or region,
whether it was a first visit, and the time. GoatCounter stores no IP addresses or cookies; the full browser
identification string and the session ID are removed before the files are saved here.

`last_hit_id.txt` tells the next export where to continue.
